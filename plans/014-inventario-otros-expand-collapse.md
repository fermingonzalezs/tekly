# 014 — Animate Inventario's "Otros" row expand/collapse and chevron rotation

- **Status**: DONE
- **Commit**: 5e82fe8
- **Severity**: MEDIUM (missed opportunity)
- **Category**: Missed opportunities / Physicality & origin
- **Estimated scope**: 1 file, 4 locations (mobile card + desktop table row, each with a chevron and a reveal block)

## Problem

Expanding a serialized "Otro" (iPad, AirPods, etc.) to show its per-unit serial/color/costo table teleports in with zero transition, in both the mobile-card and desktop-table layouts:

```tsx
// app/(app)/inventario/inventario-client.tsx:1176-1180 — current (mobile card)
{o.serializado && expanded && (
  <div
    className="mt-2.5 overflow-hidden rounded-lg border border-neutral-200 font-mono"
    onClick={(e) => e.stopPropagation()}
  >
```

```tsx
// app/(app)/inventario/inventario-client.tsx:1319-1322 — current (desktop table row)
{o.serializado && expanded && (
  <tr className="bg-neutral-50">
    <td colSpan={puedeVerCosto ? 6 : 5} className="px-5 py-3">
      <div className="overflow-hidden rounded-lg border border-neutral-200 font-mono">
```

The chevron toggling this state also swaps between two entirely different icon components with no transition at all — a hard cut, not a rotation:

```tsx
// app/(app)/inventario/inventario-client.tsx:1129-1133 — current (mobile)
{expanded ? (
  <ChevronUp className="h-3.5 w-3.5" />
) : (
  <ChevronDown className="h-3.5 w-3.5" />
)}
```

```tsx
// app/(app)/inventario/inventario-client.tsx:1270-1274 — current (desktop)
{expanded ? (
  <ChevronUp className="h-3.5 w-3.5" />
) : (
  <ChevronDown className="h-3.5 w-3.5" />
)}
```

AUDIT.md category 8 names exactly this: "state changes that teleport... where a brief transition would prevent a jarring change." Notably, this exact codebase already has the *correct* pattern for a chevron toggle elsewhere: `components/topnav.tsx:110-113` rotates a single `ChevronDown` instead of swapping two icons:

```tsx
// components/topnav.tsx:110-113 — existing correct pattern, for reference only, do not edit this file
<ChevronDown
  className={cn("h-3.5 w-3.5 transition-transform", open && "rotate-180")}
/>
```

## Target

### Chevrons — rotate a single icon instead of swapping two (mirrors `topnav.tsx`'s existing pattern)

```tsx
// mobile, target (replaces lines 1129-1133)
<ChevronDown
  className={cn("h-3.5 w-3.5 transition-transform", expanded && "rotate-180")}
/>
```

```tsx
// desktop, target (replaces lines 1270-1274)
<ChevronDown
  className={cn("h-3.5 w-3.5 transition-transform", expanded && "rotate-180")}
/>
```

`ChevronUp` remains imported and used elsewhere in this file (confirmed at lines 86 and 361, unrelated collapsible sections) — do not remove the import.

### Reveal blocks — apply the existing unused-here `animate-fade-in` token

```tsx
// mobile, target (line 1178)
<div
  className="animate-fade-in mt-2.5 overflow-hidden rounded-lg border border-neutral-200 font-mono"
  onClick={(e) => e.stopPropagation()}
>
```

```tsx
// desktop, target (line 1322)
<div className="animate-fade-in overflow-hidden rounded-lg border border-neutral-200 font-mono">
```

(The desktop fix targets the inner `<div>` inside the `<td>`, not the `<tr>` itself — this sidesteps any cross-browser inconsistency around animating table-row-level properties, and mirrors the mobile card's own fix exactly: both apply the fade to a plain block-level `<div>`.)

`animate-fade-in` (0.18s ease-out, opacity-only) is the same token already used elsewhere in this app for revealed panels (`components/topnav.tsx`'s dropdown, `components/mobile-nav-drawer.tsx`'s backdrop) — no new keyframes/animation entry needed in `tailwind.config.ts`.

## Repo conventions to follow

- `cn()` from `@/lib/utils` is the established className-merging helper — use it for the chevron's conditional `rotate-180`, exactly as `components/topnav.tsx:111-113` already does for the identical pattern.
- Reuse the existing `animate-fade-in` Tailwind utility rather than introducing a new token — this fix is additive motion on top of an existing, already-used convention.
