Un **pago** reduce la deuda de un cliente. Se registra desde la ficha del cliente o desde la sección.

<Paso n={1} titulo="Desde la ficha">
Abrí un cliente y tocá **«Registrar pago»**: el diálogo ya viene como tipo «Pago» y con el cliente elegido.
</Paso>

<Paso n={2} titulo="Desde la sección">
El botón **«Nuevo movimiento»** abre el diálogo. Elegí el cliente, el tipo **«Pago (reduce la deuda)»**, un concepto y el monto.
</Paso>

<Paso n={3} titulo="Confirmá">
El pago se descuenta del saldo. Podés cargar varios pagos parciales.
</Paso>

## Qué no se puede

- El monto tiene que ser mayor a cero y necesita un **cliente registrado** (no se puede usar «sin registrar»).
- Un pago no se asocia a una caja: es un movimiento de cuenta corriente, no de caja.
- No se puede editar después: se elimina (admin) y se carga de nuevo.
